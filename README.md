# SnapLog 📸

## About the Project
SnapLog is an Android app I created as my final project for my Android Development class.

The app allows users to log in using their email and password, take pictures, write descriptions, and save their memories. Users can log in again anytime to view their saved photos and notes.

## Features
- User login with email and password
- Take pictures using the camera
- Add descriptions to photos
- Save photos and notes
- View previously saved memories after logging in

## Technologies Used
- Kotlin
- Android Studio
- Firebase Authentication
- XML for app layouts

## What I Learned
While building this app, I learned how to:
- Develop an Android application using Kotlin
- Create different screens and user interfaces
- Set up user login with Firebase
- Work with the phone's camera
- Save and display information in an app

## Note
This project uses Firebase. To run it, a Firebase project and the appropriate configuration file are required.
